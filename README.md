# RT_Mod_CrippleSelf

Provide an ability to apply all traumas on self. Used to quicken warm-up for character builds based on traumas.

# How to aquire this ability:

Rougue Trader and companions will aquire this ability automatically when savedata loaded.
	
If it doesn't appear in your ability slot, press "C" and check the "feature" tab. It should be right under the "other" type, close to Heroic Act and Desperate Act.

# Installation:

Method 1:

1. Press "Win + R" to open CMD.

2. Copy "%userprofile%\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager\" inside and press "Enter". It should open a folder where you can find "UnityModManager.dll" file.

3. Create a new folder named "CrippleSelf".

4. Unzip the "CrippleSelf.zip" into the "CrippleSelf" folder.

5. If everything goes right, the "CrippleSelf.dll" file's location should be "UnityModManager\CrippleSelf\CrippleSelf.dll".


-- OR --


Method 2:

1. Download and install the ModFinder[https://www.nexusmods.com/warhammer40kroguetrader/mods/146].

2. Find "CrippleSelf" and press "Install".

# RT_Mod_CrippleSelf

新增一个能赋予自身所有创伤的技能. 可以用来给创伤流快速启动.

注意: 该Mod仅作为Puzzle Skip[https://github.com/Balkoth-dev/PuzzleSkip/releases]的补充, 无法跳过阿什雷卡高的谜题. 需要与ArkiveDev和Balkoth的Puzzle Skip配合使用

# 获取技能:

读取存档时, 行商浪人和同伴会自动获取该技能.
	
如果技能栏里没出现的话, 按"C"打开角色页面, 切换到"特性"页面, 在"其它"项里就能找到了. 就在"英雄壮举"和"背水一战"旁边.

# 安装:

方法1:

1. 按下"Win + R"打开"运行".

2. 把"%userprofile%\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager\"复制进去, 按回车打开Mod文件夹.

3. 新建文件夹, 重命名为"CrippleSelf".

4. 把"CrippleSelf.zip"里的文件解压到"CrippleSelf"文件夹内.

5. 一切顺利的话, "CrippleSelf.dll"所在位置应该是"UnityModManager\CrippleSelf\CrippleSelf.dll".


-- OR --


方法2:

1. 下载ModFinder[https://www.nexusmods.com/warhammer40kroguetrader/mods/146].

2. 找到"CrippleSelf" Mod并点击"Install"安装.

3. 点击上方"Mods"标签, 选择"Install Mods", 在弹出的对话框中选择"SkipBaphometPuzzles.zip"
